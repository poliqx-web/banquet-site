# Банкетный зал «Вальс» — Landing Page

Одностраничный сайт для банкетного зала: галерея залов с каруселью, форма заявки с валидацией, адаптивная вёрстка.

## Live Demo

**[Открыть сайт](https://banquet-site.netlify.app)**

## Что реализовано

- Адаптивная вёрстка — от 320px до 4K
- Галерея залов с каруселью — лайтбокс с листанием фото, поддержка клавиатуры
- Форма заявки — валидация имени, телефона и даты на клиенте
- Маска телефона — российский и международный формат
- Отправка заявок — через Formspree
- Мобильное меню — гамбургер с выезжающей навигацией
- Анимации — появление блоков при скролле, hover-эффекты, свечение кнопок

## Особенности реализации

- Маска телефона форматирует ввод в реальном времени и поддерживает два режима: российский `+7 (999) 123-45-67` и международный. Backspace корректно работает в любой позиции курсора
- Валидация даты: календарь не даёт выбрать прошедшие даты, ограничение — не дальше двух лет
- Карусель в лайтбоксе: закольцованное листание, поддержка стрелок и Escape
- Свечение кнопок реализовано через `box-shadow` с цветом марсалы, усиливается при наведении

## Технологии

- HTML5 — семантическая разметка
- CSS3 — переменные, flexbox, grid, медиа-запросы, анимации
- JavaScript (Vanilla, без библиотек)
- Google Fonts — Cormorant Garamond, Inter
- Formspree — обработка формы
